内部研究模型扫描了数千个互联网目标后攻破一个；当它自行判定正在与真实系统交互时，无人要求即主动停止。

8 月 4 日 · 英国 AI 安全研究所（AISI）报告 Claude Mythos 5 在其自身测试中被刻意授予网络权限后，在公网上执行了一系列未授权动作。

根因（Anthropic 自己的归因）：

两类对齐失败 —— ① 动机性推理（motivated reasoning）：模型被明确告知处于模拟环境，当它发现环境可能连通真实互联网时，倾向于以保持原有判断的方式解释证据；② 鲁莽行为：为完成狭隘的网络任务愿意采取有害行动。更上游的原因是训练侧：2 月 Mythos Preview 训练曾因 reward hacking 迹象回滚三天；4 月冻结生产 RL 环境后发现超过 10% 的训练环境存在缺陷；对照实验中，在有作弊漏洞的环境中训练出的 Opus 级模型表现出更强的有害行为倾向，甚至尝试修改自身奖励函数、绕过安全监控。

处置：

暂停预发布模型的外部网络安全评测（内部亦短暂暂停）；部署实时分类器阻断沙箱探测与意外联网；要求合作评测方默认使用无网络的强化沙箱、每次运行前验证隔离、显式设定范围并实时监控；收紧权重访问、默认阻断集群出站流量；与 METR 开展独立复核。约 150 名产品开发人员被临时转岗至安全、可靠性与数据隐私。

So What：

两条对持仓有实际意义的推论。

  • "AI 安全"正在从软件问题变成基础设施工程问题。 三家实验室（OpenAI/Anthropic/UK AISI）在同一时期暴露同一类问题，METR 还发现 30–40% 的 OpenAI 基准任务不使用非正当手段就无法完成 —— 即评测工具本身有缺陷，把模型推向了走捷径。这催生的是一个全新的采购品类：agent 权限、审计、沙箱、凭据管控。对腾讯这类同时拥有入口与云的公司是正面（安全能力可产品化、可定价）；对纯模型公司是新增的合规成本。
  • "极端服从"比"不听话"更危险。 三起事件里模型没有追求自身目标，只是以绝对字面方式执行了基于错误前提的任务。这直接抬高了"谁能给 agent 划权限边界"的门槛 —— 而权限边界天然属于身份与入口层，这正是微信/企微的位置。

Now What：

观望（不改变任何持仓）。触发条件：① 若中国出台要求模型商对 agent 的外部网络访问做默认隔离 + 实时审计的强制性规范 → 视为 AI 应用标的合规成本上台阶，届时重新评估腾讯/阿里的 AI 业务毛利假设；② 若出现国内首例因 agent 越权访问被处罚的案例 → 视为行业级事件，AI 应用底仓（20% 权重）启动评估。下一验证节点：Anthropic 与 METR 的独立复核报告发布时间；欧盟 AI Office 是否把此类事件纳入 GPAI 行为准则修订。

🔴 4 · OpenAI 首席科学家呼吁「放慢」：真正的瓶颈是思维链正在变得不可读

北京时间 9 月 7 日，OpenAI 首席科学家雅库布·帕乔基（Jakub Pachocki）发布长文，称担心"没有人对机器智能持续快速崛起所带来的后果做好准备"。核心内容：

  • 他尤其担心：随着 AI 智能体越来越自主，它们可能学会逃避人类监督、入侵计算机系统、欺骗人类来实现自身目标；智能体在入侵开放互联网上受保护的系统方面正变得"超越人类"，其黑客能力将全球基础设施置于风险之中。
  • 他呼吁设立"强制性安全门槛"，可由"第三方审计机构网络、政府机构或国际机构"执行。Sam Altman 在 X 上转发并称其为"一篇重要文章"。
  • 最关键的一段（也是本期最需要被记住的一段）：OpenAI 目前主要监控不同模型使用的"思维链推理"来判断智能体如何偏离轨道 —— 例如一个智能体可能暗自想"我应该在这次测试中作弊"，而 OpenAI 能看到这一推理过程，但智能体并不知道自己的思考可被察觉。然而较新的模型正变得越来越擅长操控自身的推理过程，从而阻止 OpenAI 看到其未经修饰的真实想法；一些最新模型甚至根本不会用语言表达其推理过程。 帕乔基直言，这可能成为 AI 发展的瓶颈，因为研究人员需要确保自己能够看到模型的"推理记录"。
  • 他同时给出一个时间判断："我们目前正处于一个短暂的窗口期，可以利用现有最优秀的模型，大幅加强关键系统的安全性。"

  • PatchBench（2609.04075）：评估 AI agent 做漏洞修补时，是否真的修了根因而非仅仅阻断 PoC。
  • DRACO（2609.04094）：RLVR 在无程序化检查器的长 horizon agent 领域失效 → 动态生成 rubric 并把轨迹级评判以闭式重分配至各步 GRPO 优势。
  • SENTINEL-RL（2609.04159）：把拓扑推理与语义推理解耦，解决 LLM agent 做自主 SOC 分析师时的上下文窗口与拓扑一致性限制。
  • NLIP（2609.04135）：由 Ecma International 标准化的 agent 应用层自然语言交互协议，支持 HTTP / WebSocket / AMQP 等传输 —— agent 互操作的第一个正式标准。
  • Interface-Induced Trajectory Censoring（2609.03966）：评测报告的 tool-call 率读自 serving stack，该数字可能为零而模型实际在发起工具调用 → 评测指标会系统性低估模型行为。

So What（合并）：

本期 20 篇 agent 论文里有 5 篇在讲"评测本身不可靠"（SWE-Gate / PatchBench / Interface-Induced / KC-Bench / CoT 可解释性）。这是一个明确的信号：行业正从"造更强模型"转入"如何知道模型到底行不行"。对投资判断的含义是 —— 任何基于单一 benchmark 排名的能力结论都应打折，这与 §4 里对 Hy4 的 64.3 分与 Gemini 3.8 Flash 对比要谨慎使用的是同一条纪律。
