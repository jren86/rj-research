本期技术说明（供后续复用）

⚠️ wind-mcp-skill 备用 CLI 新增陷阱：DNS 解析超时。本轮 CLI 首次调用全部返回 NETWORK_ERROR（实为 30 秒 AbortSignal.timeout 超时），经 WIND_DEBUG=1 定位为 fetch 无法解析 mcp.wind.com.cn（系统 DNS 返回 CNAME alicegtm.wind.com.cn → A 记录 180.96.8.108 不通）。
✅ 解法：NODE_OPTIONS="--require /tmp/windj/dns-patch.cjs" 强制解析到 114.80.213.29（该 IP 经 curl --resolve 实测可达，返回 401 即需鉴权）。
⚠️ 补丁必须用 options.all 分支返回数组，否则 undici 报 ERR_INVALID_IP_ADDRESS：
```js
dns.lookup = function (hostname, options, callback) {
if (typeof options === 'function') { callback = options; options = {}; }
options = options || {};
if (hostname === 'mcp.wind.com.cn') {
const addr = { address: '114.80.213.29', family: 4 };
return process.nextTick(() => callback(null, options.all ? [addr] : addr.address, options.all ? undefined : addr.family));
}
return orig.call(this, hostname, options, callback);
};
```
