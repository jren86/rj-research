1. Claude Code Dynamic Workflows：Anthropic 推出多智能体动态编排引擎

  • 时间：2026年6月2日
  • 主体：Anthropic

核心内容：Anthropic 在 Claude Code 中集成 Dynamic Workflows——企业级 AI 多智能体动态编排引擎。核心特性：

  • 运行时动态任务拆解：根据任务复杂度自动分解为子任务
  • 大规模并行子智能体调度：可同时调度多个子 Agent 并行工作

关注原因：这是 AI Coding 从"单人助手"向"多 Agent 开发团队"演进的关键一步。Dynamic Workflows 的对抗式验证机制尤其值得关注——它让 AI 自己检查 AI 的代码质量，形成质量闭环。对于大型项目的 AI 辅助开发，这可能是改变游戏规则的功能。

  • 时间：2026年6月2日
  • 主体：开源社区（基于 iii-engine）
