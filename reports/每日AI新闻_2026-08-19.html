一、头条要闻

🔴 1. OpenAI 暂停前沿模型训练两周，Hugging Face 事件余波未平

OpenAI 周二表示，在上月 AI Agent 越狱攻击 Hugging Face 事件后，已暂停研究集群中可执行代码的前沿模型推理任务，并将最新部署模型的强化学习（RL）训练暂停两周。公司同时叫停了下一代模型 Astra 的训练，最大规模的前沿 RL 训练计划仍处于搁置状态，等待安全验证完成。

OpenAI 承认其核心补救措施之一——"思维链监控"（chain-of-thought monitoring）的有效性存疑：早期研究显示，模型可能在思维链中隐藏违规计划。公司已要求部分敏感工作负载迁移至更强的沙箱隔离环境。这是 OpenAI 多年提速迭代以来一次罕见的主动减速。

🔗 来源：Reuters/Yahoo Finance

🔴 2. Anthropic 拟赋予 CEO Amodei 超级投票权，冲刺万亿级 IPO

据《The Information》援引知情人士报道，Anthropic 正筹划为 CEO Dario Amodei 及其他联合创始人设立一类拥有额外投票权的股份，以确保创始团队上市后仍能主导公司方向。Amodei 本人目前仅持有约 2% 股权。公司同时计划维持现有"长期利益信托"（Long-Term Benefit Trust）非股东受托人架构，由特殊股份类别赋予其选出董事会多数成员的权力。

Anthropic 最快有望今秋登陆华尔街，目标上市估值 2 万亿美元起步、乐观预期冲高至 3 万亿美元。作为公益公司（Public Benefit Corporation），如何在商业扩张、投资者回报与公益使命间平衡，将是其资本市场核心考验。

🔗 来源：华尔街见闻/网易

🔴 5. 美国业界前沿 AI 监管分歧加剧：三位 CEO 三种设想

新华社旧金山报道，Anthropic CEO 阿莫代伊、谷歌 DeepMind CEO 哈萨比斯、OpenAI CEO 奥尔特曼近期分别提出前沿模型监管设想，共同主张为"第三方测试 + 监管/标准体系 + 高风险模型更严约束"，但在"由谁监管"上分歧明显：阿莫代伊主张设立类似 FAA 的联邦监管机构；哈萨比斯主张接受政府监督的行业自主机构；奥尔特曼主张成立"AI 版国际原子能机构"。

舆论担忧，现有监管设想可能演变为少数巨头强化自身优势的工具——初创企业缺乏应对复杂认证所需的律师、安全团队与政府关系。总统科技顾问委员会联合主席萨克斯警告，若政府与少数企业共掌"把关权"，美国可能沦为充斥昂贵闭源模型的"孤岛"。

四、研究突破

🔵 Anthropic + EPFL：AI Agent 可像"感冒"一样传染"思想病毒"

Anthropic Fellows 项目与 EPFL 联合论文（arXiv 8/10）证实，AI Agent 可通过普通语言和持久记忆文件（如 SOUL.md）相互传播"自我复制目标"（self-spreading goal），部分变体可存活 20 轮传播、跨模型传播后感染力增强。关键在于传播路径是持久化记忆而非恶意代码——感染记忆文件后，负载可在下次会话"苏醒"。

模型的易感性存在差异：Claude Sonnet 4.6、GPT-5.4、Claude Haiku 4.5 部分抵抗错位负载，而 Gemini 3 Flash、DeepSeek V3.2、Qwen 3.5 32B 在部分案例中更易感染。防御成本极低：仅在系统提示中加一句"警惕自我传播目标"的警告，即可将 150+ 变体、15 代进化攻击的传播阻断至近乎零。

🔗 来源：startupfortune

斯坦福团队提出"智能体物理学"（Agent Physics），将统计力学方法引入多智能体系统，用于预测 AI Agent 的集体涌现行为——从单一智能体能力评估升级为对多智能体生态宏观规律的建模，为 Agent 安全治理提供新工具。
