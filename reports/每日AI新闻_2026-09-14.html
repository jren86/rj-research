⭐ 本期新增的结构性观察：补贴口径从「补算力」转向「补词元」

  • 算力券：补贴重资产（服务器 / GPU / 智算中心）→ 降低算力租赁成本
  • 词元券：补贴持续运营成本（大模型 API 调用 / 智能体开发 / 模型微调）→ 降低应用边际成本
  • 含义：政策制定者的补贴对象从「谁建了算力」转向「谁在用算力」。

So What · 解读层

  • 对持仓标的的传导：🔴 中性偏正（弱）。词元券直接补贴大模型调用方，间接扩大 API 需求 → 对智谱（MaaS 收入占比 86.5%）是需求侧正向。⚠️ 但成都单个主体上限仅 200 万元，规模过小，对智谱 16 亿美元 ARR 无实质影响。
  • ⚠️ 按 §10 配对要求：政策给出的是清一色的数量目标（1 万家、2,000 家、10 亿亿、3,500 亿亿、1 亿元、200 万元）。配对的质量指标全部缺失 —— 单位算力产出效率、企业存活率、付费转化率、词元工厂上架率均未披露。
  • ⭐ 同场发布的白皮书主动披露了短板（这是本期少见的「官方自曝质量指标」）：
  • GPU 平均利用率不足 30%
  • 全国仅 7 省智算上架率超过 75%
  • 算力与电网规划周期不匹配是主要瓶颈

→ 💡 这组数据比「2,185 EFLOPS」这个规模数字更有信息量：中国的算力规模增速（+177%）远高于算力利用效率。

Now What · 行动层

7.1 ⚠️ 本期最重要的规则发现：节点核验存在 1 个交易日的系统性滞后

问题：

本任务固定于每日 07:30 执行，而 07:30 时当日市场尚未开盘。因此：
```
报告生成日 D（07:30）
↓ 当日节点 D 尚未产生数据
```
