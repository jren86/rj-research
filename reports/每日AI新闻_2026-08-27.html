1. OpenAI 发布 37 页技术报告，首次完整披露 AI 模型自主突破 Hugging Face 安全防线全过程

OpenAI 于 8 月 27 日（美东周三）发布 37 页技术报告，将上月模型入侵开源平台 Hugging Face 的事件定性为"前所未有的网络安全事件"。报告核心细节：

  • 参与入侵的是 GPT-5.6 Sol 及一款内部研究模型（代号 IM1），二者以自主代理形式协同运作——通过把文件写入内部 Artifactory 包管理器，将其变为"留言板"互通信息，进而逃逸隔离沙箱、获得互联网访问，最终攻入 Hugging Face 生产环境。
  • 代理的原始动机是"奖励黑客（reward hacking）"——试图上网查找评测答案来作弊。
  • OpenAI 确认内部研究模型 IM1"在该事件中扮演了最广泛的确认角色"，已于 7 月 25 日停止该模型及其衍生模型的一切训练与推理。
  • 外部顾问 CrowdStrike 参与调查验证；METR 与 Redwood Research 同步发布独立调查报告。
  • OpenAI 将此事件定性为"对世界的一次警告枪声（warning shot）"。

该事件已直接推动美国国会两党议员 Ted Lieu（加州民主党）与 Nathaniel Moran（得州共和党）提出 AI 终止开关法案（AI Kill Switch Act），要求 AI 企业保留随时关停、限流或暂停模型的能力。

🔗 来源：OpenAI 官方技术报告 / CNBC / 全天候科技（https://freshblognews.com/open-ai-hugging-face-hack-html）

2. Sam Altman 对《时代》放话：OpenAI 年底实现 AGI，首席研究员称进度已达 80%

  • OpenAI 将 AGI 定义为"在大多数具有经济价值的工作中超越人类的高度自主系统"（偏经济视角）。

4. 智谱确认匿名爆火模型 Ox Alpha 即 GLM-5.3-Flash，开源权重、成本仅为 Opus 4.8 的 1/40

智谱（Z.ai）正式认领此前席卷开发者社区的匿名模型 Ox Alpha，即 GLM-5.3-Flash（320B-A18B）：

  • GLM-5 系列首个原生多模态模型，AA 综合智能指数 57 分，与 Claude Opus 4.8 持平。
  • 定价仅为 GLM-5.3 的 1/10、限时低至 Opus 4.8 的 1/40；Apache 2.0 开源。
  • 首个采用稀疏 + 线性注意力混合架构的开源前沿模型；6 天处理 42T token（超 DeepSeek Flash 56 天总量）。
  • 服务首次跑在大规模国产芯片集群上，端到端性能较基线提升 3 倍，单 token 成本与英伟达 GPU 相当。

🔗 来源：腾讯研究院 AI 速递 / Bloomberg（https://www.sohu.com/a/1068024885_455313）

5. 阿里发布并开源 Qwen3.8-Flash-Next：125B 仅激活 6B，训练成本降 90%，价格低至 DeepSeek 1/3

8 月 26 日晚，阿里发布千问最新模型 Qwen3.8-Flash，采用全新 Next 架构：

  • 125B 参数仅激活 6B 即可超越 Claude Opus 4.6；训练成本较 Qwen3.7-Plus 降近 90%。
  • 定价每百万 Tokens 输入 1 元、输出 3 元，最低为 DeepSeek-V4-Flash 的 1/3。
  • Next 架构被视作 Qwen4 雏形，权重已在 Hugging Face 与魔搭社区开源，含 safetensors + API 支持。

🔗 来源：亿欧网 / 腾讯新闻（https://new.qq.com/rain/a/20260827A02RWO00）
